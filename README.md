## Key Bindings:

- Get Cursor: `Esc`
- Movement: `WASD`
- Sprint: `Ctrl`
- Move camera Up: `Spacebar`
- Move camera down: `Shift`
- Debug Mode: `F3`
- Toggle Hints: `H`
